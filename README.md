Code for the analysis of Cross-sectional study measuring impulsivity and inhibitory control in Parkinson’s disease and impulse control disorders (2019-2026)

The demographics.R file needs to be run before anything else, as it generates the moca_exclusions.csv file which helps us exclude participants from task data who didn't pass the MoCA screening.

The remaining files can be run in any order. They all follow the same general pattern, which is defined by the pre-registration: https://osf.io/y8drq/files/frzpv

Code for some of the experiments can be found here: https://github.com/jspickering/Experiments
